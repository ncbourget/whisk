# Art-direction audit — before the second pass

September 17, 2026. Reviewed all eight public routes, the notebook, the shared template, content, renderer, styles, and interaction scripts. The working tree was clean at the start. Only the new written brief was attached: the Illustrator screenshot, actual logo assets, packaging originals, and trailer reference photos are still absent.

| Area | Keep | Change |
| --- | --- | --- |
| Typography | Readable body copy and semantic headings | Georgia's tight large headlines, miscellaneous italics, Trebuchet, and tracked labels create competing voices. Test three serif candidates and restrained grotesks; add one mono role. |
| Color | Paper and metal material contrast | Remove brick-red CTA, green ink, and multiple sage/beige component fills. Use provisional periwinkle/navy, silver, paper, white. |
| Layout | Normal routes and usable header | Repeated kicker/headline/right-link pattern makes every section look alike. Compose a compact hero/status area, asymmetrical featured bakes, one blue story field, and a utilitarian location section. |
| Spacing | Constrained text measures | 600px minimum hero, 75px repeated sections, and generous padding compound. Tighten functional areas; reserve room for food/trailer. |
| Buttons | Obvious order action, large hit areas | Red fill, lift-on-hover, and repetitive arrows. Use flat navy/reversed signage-like rectangles; arrows only when informative. |
| Illustration | Lightweight original whisk SVG, decorative semantics | Remove repeated stars and slogan/illustration combinations. Use the whisk once meaningfully; reserve slots for licensed assets. |
| Trailer | Central SVG and real service-window link | Remove three captions, coordinate all ink/silver/blue materials, refine hardware and subtle reflections. Do not claim new proportions match unavailable reference photos. |
| Copy | “Good things. Small batches.” and useful policies | Remove cumulative “little”, flour, crumbs, detours, and possibilities slogans. Replace with direct status, menu, location, and contact text. No invented offerings/locations. |
| Menu | Product metadata, filters, disclosures, sold-out behavior | Consistent data typography and stronger name/description/price hierarchy; varied featured-image scale. Preserve owner-selected crop shapes. |
| Mobile | Visible navigation, logical order, existing breakpoints | Status appears too late after large hero. Show it before artwork. Ensure new font metrics don't crowd controls. Simplify hatch lettering on small screens. |
| Editor | All fields, save/preview, backup, upload, import/export | Keep utilitarian; use sans UI headings except the main heading, mono labels/status, neutral inputs and shared navy/blue tokens. |
| Accessibility | Skip link, native controls/details, focus, alt text, reduced motion | Avoid pale blue text on ivory or white on powder blue. Increase several tiny labels; preserve visible focus on dark/blue backgrounds and at zoom. |
